Algorithm Analysis

Greedy strategy. The highest bid b* is the buyer willing to pay most; the lowest ask a* is the cheapest seller. If b* < a*, then no pair is feasible, since every other bid ≤ b* < a* ≤ every other ask.
Exchange argument. Let OPT be a feasible matching that does not pair b* with a*. Let b* be paired with a′ (a′ ≥ a*) and a* with b′ (b′ ≤ b*) (or unmatched). Swap partners: b*–a* is feasible since b* ≥ b′ ≥ a*, and b′–a′ is not required; the number of matched units and total energy don't decrease, so a solution containing b*–a* is at least as good. Hence the greedy choice is safe and no feasible match is missed.
Loop invariant. At the start of each iteration, the Max-Heap root is the highest remaining bid, the Min-Heap root is the lowest remaining ask, and all trades emitted so far are feasible. Initialization: heaps built from all open orders, trades = ∅. Maintenance: after a trade, the remainder is reinserted, so heap order holds. Termination: when a heap empties or root bid < root ask, no feasible pair remains by the argument above.
Complexity. Heap build: O(n). insert/extract: O(log n). Each iteration removes at least one order completely, so at most n+m iterations → heap matcher O(n log n). Naive matcher scans all orders each iteration: O(n) × O(n) = O(n²).
